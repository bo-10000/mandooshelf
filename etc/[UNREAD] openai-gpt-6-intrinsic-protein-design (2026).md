## 한 줄 요약

전용 단백질 AI 모델을 부르지 않고 **추론과 코드 작성만으로** 단백질의 3D 구조와 아미노산 서열을 설계하는 GPT-6 계열의 능력을 보인 논문(프리프린트 "GPT-6 as a Universal Foundation Model for Protein Biology: Beyond Specialized Models"). 계산 평가 14개 과제에서 전용 모델과 비슷하거나 나은 성능을 냈고, 실험실 검증에서 GPT-6.2가 설계한 미니바인더 322개 중 35개(10.9%)가 5개 표적에 결합했으며, 항체 결합 루프 재설계는 182개 중 128개(70%)가 결합했다. 다만 후보 필터링은 여전히 전용 모델(Boltz-2·OpenDDE·ESMFold2)에 의존했고, 서열만으로 전체 구조를 예측하는 일은 약하다.

> 논문: OpenAI, 2026-11-24(프리프린트). 실험실 검증 협력: Onava.

## 문제 구도 — 전용 모델은 잘하지만, 조합하는 데 전문성이 든다

- 단백질 설계는 두 단계로 나뉜다. **백본(3D 구조) 생성**(주로 RFdiffusion)과 **서열 설계**(주로 ProteinMPNN), 그리고 그 사이의 후보 필터링.
- 전용 모델은 정해진 입력·제약만 받고, **새 정보를 넣으려면 코드를 고치거나 다시 학습**해야 한다. 그래서 여러 모델을 조합·조율하는 데 상당한 전문성이 필요하다.
- 주장하는 대안: 범용 모델 하나가 **자연어 지시 + 코드 도구**로 여러 전용 모델의 일을 대신하고, 새 요구에 프롬프트만 바꿔 적응한다.
- 결국 "모델이 생물학을 아느냐"보다 **어디까지 스스로 하고 어디서 전용 모델이 필요한가**를 재는 실험이다.

## 어떻게 하는가 — 추론하고 코드를 써서 구조·서열을 만든다

- 모델은 대상 단백질 구조를 받고, 결합할 위치를 표시받으면 **코드를 작성·실행해** 후보 3D 구조를 만든다. 수학·물리·화학 지식과 서열·구조의 반복 패턴을 함께 쓴다는 정황이 모델의 추론문·코드에 드러난다(예: IL-7Rα 결합용 설계에서 표면을 살피고, 코일 5개를 배치하고, 두 단백질이 맞물리는지 확인).
- 조절 단위가 자연어라 **원자 단위 결합 하나부터 단백질 전체 모양까지** 같은 모델로 지시할 수 있다. 이미 아는 결합 원자쌍을 주고 나머지 배치를 묻는 식으로 과제를 바꿔도 재학습이 필요 없다.
- 실험실 검증은 구조 → 서열 → 후보 선별 → 합성·측정 순서로 진행됐다.
- 서열은 **SolubleMPNN**이 제안하고, 접힘·결합 예측 모델로 후보를 걸러 Onava가 합성·측정했다. 즉 "구조 설계"는 GPT-6.2, "서열 공급"은 전용 모델인 **혼합 파이프라인**이다.

## 실험실 결과 — 실제로 결합한 비율

- **실험 1: 표적에 붙는 미니바인더 설계**
  - 5개 표적에 대해 322개를 합성·측정 → **35개(10.9%)**가 의도한 표적에 결합.
  - 표적별: PD-L1 5개, IL-7Rα 3개, TrkA 1개, VEGF-A 8개, IL-17A 18개.
  - 원 RFdiffusion 논문의 적중률이 더 높지만, 저자들은 **검증 전 필터링 강도와 '결합'의 정의**에 따라 크게 달라진다고 밝힌다. 계산 점수에서도 GPT-6.2의 3D 설계는 RFdiffusion보다 약간 낮았고, 내부 최신 모델이 더 높았다.
- **실험 2: 주어진 3D 구조에 새 서열 설계**
  - 확인된 미니바인더 3종에 서열을 새로 제안: **MDM2 75/88(85%), VEGF-A 26/42(62%), PD-1 8/59(14%)** 결합.
  - 원 서열과의 중앙값 차이는 VEGF-A 50%, MDM2 43%, PD-1 15% — 그냥 베낀 게 아니다.
  - 공개되지 않은 자체 생성 구조 3종에서 새 서열 107개 → **14개(13.1%)** 결합. 같은 PD-L1 구조에 서로 다른 서열 두 개(원본과 90개 중 52·58개 다름, 둘끼리는 44개 다름)가 모두 결합 → **암기 이상의 근거**라는 주장.
- **항체 결합 루프 재설계**
  - IL-4Rα에 붙는 VHH 6종의 결합 루프 3개 서열을 새로 설계: 182개 중 **128개(70%)** 결합.
  - 치료 항체 5종의 루프 아미노산 절반을 바꾸는 정밀 편집: 272개 조각 중 **179개(66%)**가 원 표적(PD-1·PD-L1)에 결합.

## 계산 평가 — 전용 모델과 비교한 숫자

- **형태 지정 설계**: 코일/스트랜드 구성과 개수를 자연어로 지정하면 거의 그대로 따랐다. 특정 표면 잔기를 묻거나 β-sheet–β-sheet 상호작용을 지정하는 식의 세부 제약도 지시할 수 있다.
- **모티프 스캐폴딩(MotifBench 30과제)**: 내부 최신 모델 **43.7%** vs RFdiffusion **27.8%**(모티프 보존 + 전체 구조 일치 기준, 계산 검증).
- **접힘 지정(CATH, 200과제)**: 내부 최신 모델 **18.9%** vs 전용 모델 Proteina **17.1%**.
- **도킹(PoseBusters)**: 위치·방향 일치 GPT-6.2 **93%**, 내부 최신 **96%**, 전용 DiffDock-L **50%**.
- **결합 원자쌍을 알려준 도킹(Scarpino 179개)**: **92% / 97% / DiffDock 60%** — 아는 정보를 프롬프트로 넣을 수 있는 게 범용 모델의 이점.
- **항체-표적 배치(DockQ, 곁사슬 정보 숨김)**: GPT-5.6 0.05 → GPT-6 0.28 → GPT-6.2 0.57 → 내부 최신 **0.81**. 세대마다 개선.
- **변이 효과 순위**: 안정성 데이터 265세트에서 순위 상관 0.41 → 0.52 → 0.57 → **0.66**. 네 데이터셋 모두에서 GPT-6.2·내부 모델이 전용 ESM2-650M보다 정확.
- **약점: 서열→전체 구조 예측**. TM-score 평균 0.16 → 0.26 → **0.38**인데 전용 ESMFold2는 **0.93**. 항체 CDR 루프 채우기는 상당히 정확했지만 ESMFold2가 여전히 우위.

## 저자들이 인정한 한계

- 설계 캠페인 자체가 **Boltz-2·OpenDDE·ESMFold2로 후보를 거르는 데 의존**했다. 보인 것은 두 단계(백본 생성, 서열 재설계)에서의 대등한 능력이지, **전용 모델 없이 끝까지 가는 zero-shot 파이프라인이 아니다**.
- "능력의 들쭉날쭉한 경계(jagged capability frontier)" — 과제별 편차가 크고 전체 구조 예측은 뚜렷이 뒤진다.
- 구조→서열 추론의 높은 정확도는 **암기·생성 과정의 흔적**일 수 있어 낯선 단백질 성능을 보장하지 않는다.
- 결합은 첫 단계일 뿐. 특이성·안정성·생물학적 활성·치료 안전성은 별도 검증이 필요하다.

## 다음 목표

- 더 어려운 표적의 미니바인더 찾기.
- 결합 이후의 효과(예: 암세포 사멸)와 선택성·제조 가능성까지 설계.
- 여러 표적 동시 결합 분자, RNA, 소분자, PROTAC으로 확장.
- 생물보안 위험은 Preparedness Framework 기준으로 평가·완화.
