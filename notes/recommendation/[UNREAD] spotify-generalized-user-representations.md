## 한 줄 요약

스포티파이가 **오디오·협업 신호를 3개 시간 스케일로 모아 오토인코더로 압축한 '사용자 임베딩 하나'** 를 만들고, 검색·랭킹·후보 생성 같은 다운스트림이 **가벼운 head만 붙여** 쓰는 프로덕션 프레임워크. 6억 명 리스너 규모에서 **콜드스타트·신선도·안정성**을 동시에 잡은 운영 설계가 핵심이다.

> 글 2025-09-18. 논문: Ghazal Fazelnia et al., *Generalized User Representations for Large-Scale Recommendations and Downstream Tasks*, RecSys 2025 (Industry).

## 문제 배경

- 개인화가 홈·검색·플레이리스트 생성·랭킹을 모두 떠받치는데, 사용자 취향은 **장기 선호 + 기분·상황·신곡에 따른 단기 변화**가 겹친다.
- 파운데이션 모델·생성형 추천으로 가려면 **여러 제품에 통하는, 갱신이 빠른, 전이 가능한** 사용자 표현이 필요하다. 요구사항 네 가지: ① 제품 전반 일반화 ② 변화에 빠른 적응 ③ 콜드스타트 ④ 효율적 확장.
- 실무적으로는 피처를 팀마다 손으로 만드는 비용이 문제였다.

## 큰 구도: 2단계 (표현 학습 → 전이)

- **① 표현 학습 (오토인코더)**: 인코더가 **compact·의미적으로 안정적인 임베딩**을 만들고, 디코더가 입력을 재구성 → 여러 과제에 쓸 정보가 임베딩에 남도록 강제
- **② 전이 학습 (다운스트림)**: 검색·랭킹·후보 생성·생성형 모델이 임베딩을 **피처/최근접 이웃 검색/생성 조건**으로 쓰고, **가벼운 head만** 학습 → 팀 간 느슨한 결합

**입력 구성**
- 두 개의 모달리티 인코더로 트랙 임베딩(80차원)을 만든다: **오디오 인코더**(음향 유사도), **협업 인코더**(플레이리스트 동시 등장).
- **3개 시간 스케일**로 상호작용을 집계: 약 6개월(핵심 관심) / 1개월(중기 변화) / 1주(신선한 의도).
- 여기에 맥락·인구통계·온보딩 신호를 융합해 오토인코더에 넣는다. 학습 시 **denoising**을 적용해 희소성·노이즈에 견고하게 만든다(콜드스타트·행동 변화 대응의 바탕).

## 서빙의 세 가지 요구

1. **응답성**: 배치 추론으로 전 사용자 커버리지(비활성 사용자 포함) + **활동 이벤트가 트리거하는 NRT 추론**으로 몇 분 내 갱신, 온라인 피처 스토어에 저장. 배치는 커버리지, NRT는 신선도.
2. **콜드스타트**: 신규 사용자는 이력이 없으므로 **온보딩 신호**(고른 아티스트·장르·언어)를 기존 사용자와 **같은 파이프라인**으로 인코딩하고 인구통계를 더해 첫날부터 개인화. 행동이 쌓이면 자연히 행동 기반으로 이동.
3. **안정성**: 재학습마다 임베딩 좌표가 흔들리면 다운스트림이 깨진다(검색 결과가 추천과 어긋남). **Batch Management**: 재학습마다 **batch ID**를 붙이고, 다운스트림을 새 배치와 **동기화해 재학습**하며, 통합이 끝날 때까지는 **레거시 배치로 서빙**한다. 항상 같은 의미 공간 안에서 비교되게 만드는 장치.

## 성과

**오프라인 예측 정확도 (다음 트랙 스트리밍 예측)**
- 콜드스타트(**가입 후 4시간 이내**): **+5%**
- 7일 예측: **+2%**

**온라인 A/B (프로덕션 배포 후)**

- **후보 생성 (홈 선반)**: 발견 **+2.9%**, 아이템→스트림(i2s) 전환 **+13%**
- **검색 재정렬**: 전체 **+0.06%**, 팟캐스트 검색 성공 **+0.76%**
- **홈 랭킹**: 음악 발견 **+0.20%**, 소비 점유율 **+0.05%**

- 인프라 비용 절감도 함께 보고했다(구체 수치는 글에 없음).
- **Ablation** — 각 요소가 실제로 일하고 있다는 증거:
  - 온보딩 신호 제거 → 온보딩 정렬 클러스터 nDCG@50 **-13.8%**
  - 모달리티 인코더(오디오+협업) 제거 → 7일 AUC **-4.2%**, 최애 아티스트 클러스터 nDCG@50 **-37.1%**
  - 정적 사용자 피처(예: 가입 국가) 제거 → 국가 정렬 클러스터 nDCG@50 **-12.1%**
